# Transcripts

Extractions are made with [prompts/transcript-extraction.md](../prompts/transcript-extraction.md). Channel scans are folded into the creator's file in `03-modern-creators/` and logged in [youtube-channel-scan-log.md](youtube-channel-scan-log.md). A separate per-video file is optional: `<creator>-<video-slug>.md`.

Store only the extraction (frameworks, rules, triggers, examples). Do not commit full raw transcripts; they are the creator's copyrighted content.
