# Video Ad Script Templates

Timings are for vertical short-form (Reels, TikTok, Shorts). Scale them for longer placements. Spoken pace is about 2.5 words per second, so 30 seconds is roughly 75 words.

For animated formats (skeleton, crochet, singing, claymation, talking objects), write the script here first, then follow that format's SOP in `01_Skills_and_SOPs/`.

---

## 1. Hook -> Problem -> Agitate -> Solution -> CTA (the workhorse, 30s)
| Time | Beat | Line template |
|---|---|---|
| 0-3s | Hook | "[Call-out or bold claim that names their pain]" |
| 3-8s | Problem | "If you [situation], you know [specific frustration]." |
| 8-14s | Agitate | "And it gets worse: [cost, consequence, what it's stealing from them]." |
| 14-24s | Solution | "[Product] [mechanism] so you [result] in [time]. [One proof point]." |
| 24-30s | CTA | "[Smallest step]. [Reason to do it now]." |

## 2. UGC testimonial (30-45s)
| Beat | Template |
|---|---|
| Hook | "I didn't think [product] would work for me, because [objection]." |
| Before | "I was [before state, specific]." |
| Turning point | "Then [how they found it / what they tried]." |
| After | "Now [after state, with a number or visible change]." |
| Proof moment | [Show it: screen, result, product in use] |
| CTA | "If you're [same situation], [CTA]." |

## 3. Founder story (45-60s)
Setup (who I am, the problem I had) -> Conflict (what I tried that failed) -> Discovery (the mechanism) -> Result (for me, then for customers) -> Invitation (CTA). This follows Furr's 3-step story: Setup, Increasing conflict, Resolution.

## 4. Demo / "watch this" (15-30s)
| Beat | Template |
|---|---|
| 0-2s | Show the result or the problem visually, with no talking-head intro |
| 2-5s | "Here's how [product] does [result] in [time]." |
| 5-20s | Show 3 steps, one line each |
| Last 5s | Result + CTA |

## 5. Us vs. Them (20-30s)
"Most [alternatives] [common flaw]. We [different approach], so you [benefit]. [Proof]. [CTA]." Use it for product-aware audiences. Don't name competitors unless legal has cleared it.

## 6. Listicle ("3 reasons...", "5 mistakes...") (30-45s)
Hook: "[Number] [mistakes/signs/reasons] [audience] [pain]." Then one line per item, with the last item leading into the product. Then the CTA.

## 7. Objection-buster (15-30s)
"'[Top worry, quoted from a real customer]' That's the #1 thing we hear. Here's the truth: [answer + proof]. [CTA]." Use it for retargeting.

## 8. Street interview / reaction (30-60s)
Ask strangers the problem question, show the reactions, reveal the product or answer, CTA. It works for unaware audiences because it opens with people, not a pitch.

---

## Script QA before recording
- [ ] Hook works with the sound OFF (on-screen text says the same thing).
- [ ] First frame is visually interesting on its own.
- [ ] One idea, one CTA.
- [ ] Word count fits the length (about 2.5 words per second).
- [ ] Captions are planned in the editor, not baked into AI generations.
- [ ] Passes [ad-scorecard.md](../ad-scorecard.md).
