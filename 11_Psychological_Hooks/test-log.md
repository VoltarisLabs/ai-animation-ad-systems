# Test Log and Naming Convention

Every ad that goes live gets a row here. This log is how the team gets better, not just busier.

## Naming convention
```
[Brand]_[Audience]_[Angle]_[HookType]_[Format]_[Version]
e.g.  ACME_NewGymOwners_Problem_CallOut_UGC30_v2
```
Use the same name in the ad platform, the file name and this log.

## Rules
1. **One variable per test.** Change the hook OR the angle OR the format, never all three at once.
2. **Test hooks first.** Keep the body and offer fixed and run 3 to 5 hooks.
3. **Enough data before you judge.** Don't call a result until each ad has spent at least 2 to 3x the target cost per result, or has about 50+ conversions for the event you're optimizing for.
4. **Kill rule:** spend 3x the target CPA with zero conversions = off.
5. **Scale rule:** increase budget about 20% at a time on winners.
6. **Log losers too.** A losing angle is information.

## Monthly review (30 min)
- Which hook types win for each audience?
- Which angle wins (Problem / Opportunity / Prediction)?
- Does the pre-launch scorecard predict results? If high-scoring ads lose, adjust the scorecard weights.
- Add winning hooks to `hook-formulas.md` as proven examples, and winning ads to `swipe-file.md`.
