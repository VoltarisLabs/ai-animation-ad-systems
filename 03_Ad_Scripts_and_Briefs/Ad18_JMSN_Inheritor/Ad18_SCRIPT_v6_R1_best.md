## ⚑ Needs the owner's yes before it runs
1. **A bonus / extra cash** at closing (hook + close).
2. **"Fast"** and **paying next month's mortgage or moving costs** (line 2).
3. **An offer within 24 hours** (line 8).

Claiming any of these when it isn't true is a deceptive ad (FTC). If one is only partly true (e.g. moving costs up to a set amount), the line changes to say exactly that.
